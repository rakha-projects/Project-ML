BAB B

Latar Belakang & Signifikansi Masalah

ANALISIS ANCAMAN SIBER
REKAYASA SOSIAL INDONESIA
[1] Maraknya Kejahatan Smishing

SMS Phishing (Smishing) merupakan vektor utama rekayasa sosial di Indonesia. Berdasarkan data BSSN & Kominfo, kerugian masyarakat akibat penipuan APK dan transfer fiktif mencapai ratusan miliar rupiah per tahun.

[2] Karakteristik Teks Sangat Informal

SMS bahasa Indonesia dipenuhi singkatan gaul (*kata alay*), typo disengaja, permutasi nomor telepon, tautan acak (*shortlink*), dan manipulasi psikologis yang mengelabui filter penyedia telekomunikasi.

[3] Ketiadaan Filter Cerdas pada GSM

Berbeda dengan email yang memiliki filter spam berlapis (SPF/DKIM), jalur SMS GSM konvensional tidak memiliki mekanisme verifikasi pengirim, sehingga pengguna sangat rentan menjadi korban.

Signifikansi Solusi: Diperlukan sistem cerdas berbasis Natural Language Processing (NLP) yang mampu menormalisasi bahasa gaul, menyamarkan entitas acak (*entity masking*), serta memberikan klasifikasi multi-kelas (Normal, Penipuan, Promosi) dengan jaminan akurasi tinggi dan minim *false alarm*.

BAB F

Temuan Utama Exploratory Data Analysis (EDA)

STATISTIK DESKRIPTIF &
POLA PEMBEDA ANTAR KELAS
[1] Anomali Panjang Teks

SMS Normal berkarakteristik sangat pendek (rata-rata 70.5 karakter, median 59). Sebaliknya, SMS Penipuan rata-rata 150.6 karakter dan Promosi 140.6 karakter untuk memuat instruksi panjang dan tautan.

[2] Indikator Siber (Heuristik)

78.3% SMS Penipuan memuat tautan web (shortlink), dan 64.2% mencantumkan nomor kontak pribadi/WhatsApp. Pada SMS normal, kemunculan tautan dan nomor ponsel mendekati 0%.

[3] Leksikon Kata Pembeda

Penipuan didominasi kata: pinjaman, tunai, hadiah, cek, shopee, rekening, bunga 0%. Promosi didominasi: kuota, paket, gb, flash, telkomsel. Normal: kuliah, perpus, jam, makan, besok.

Korelasi Pearson Terhadap Label Penipuan:

Fitur heuristik tautan URL (r = +0.68) dan nomor kontak pribadi (r = +0.61) memiliki korelasi linear positif paling kuat terhadap klasifikasi penipuan, membuktikan bahwa indikator siber sangat valid mendukung Machine Learning.

BAB G

Pipeline Preprocessing & Entity Masking

REDUKSI OVERFITTING &
NORMALISASI BAHASA GAUL
[1] Kamus Slang Bahasa Indonesia (100+ Lema)

Menormalisasi singkatan SMS menjadi bentuk baku untuk menyatukan representasi fitur:

  • dpt → dapat | sy → saya | hub → hubungi
  • rek → rekening | tsel → telkomsel | pinjol → pinjaman online
  • bca/bri → bank | jt/juta → juta | lgsg → langsung
[2] Entity Masking Berbasis Regular Expression

Mengganti token unik dengan representasi generic token:

  • URL / Tautan Web → diganti menjadi [url]
  • Nomor Telepon / WA GSM → diganti menjadi [nomor]
  • Nominal Uang Rupiah / Valas → diganti menjadi [nominal]
  • Kode USSD Dial Operator → diganti menjadi [kode]
Justifikasi Ilmiah Entity Masking: Jika URL (seperti bit.ly/undian123) dibiarkan mentah, model akan menghafal link spesifik tersebut dan gagal mendeteksi link baru (*overfitting*). Dengan token [url], model mempelajari pola bahwa *"keberadaan tautan"* adalah ciri khas penipuan.

Pengembangan Model & Metodologi Pelatihan

STRATIFIED 80:20 SPLIT &
5-FOLD CROSS VALIDATION
1. Ekstraksi Fitur TF-IDF

Menggunakan TfidfVectorizer dengan konfigurasi:
• N-Gram range: (1, 2)
• Min document frequency: 2
• Sublinear TF: True (1 + log(tf))
Menghasilkan 3.006 dimensi fitur leksikal.

2. Pembagian Data Uji Murni

Menerapkan Stratified 80:20 Split:
• Data Latih: 910 sampel (80%)
• Data Uji Independen: 228 sampel (20%)
Data uji diisolasi murni untuk mencegah *data leakage*.

3. 3 Algoritma Pembanding

Melatih dan menala hiperparameter 3 algoritma wajib:
• Multinomial Naive Bayes (α=0.3)
• Logistic Regression (C=2.5, balanced)
• Linear SVM (CalibratedClassifierCV)

Validasi Silang (5-Fold Stratified Cross Validation):

Setiap algoritma diuji kestabilannya pada 5 lipatan data latih yang berbeda untuk memastikan model tidak hanya beruntung pada satu subset data tertentu.

BAB J

Justifikasi Ilmiah Pemilihan Logistic Regression

CHAMPION MODEL SELECTION
5 LANDASAN AKADEMIK
[1] CV Macro-F1 Tertinggi (0.9410)

Mengungguli Naive Bayes (0.9374) dan Linear SVM (0.9360) pada validasi silang 5-lipatan. Ini membuktikan model paling konsisten di berbagai kombinasi subset data.

[2] Recall Penipuan Sangat Tinggi (95.45%)

Dalam keamanan siber, metrik utama adalah Recall Penipuan. Meminimalkan *False Negative* (penipuan berbahaya lolos dianggap normal) sangat krusial agar korban tidak tertipu.

[3] Zero False Alarm pada Normal (100%)

Tidak ada satu pun SMS normal yang salah dituduh sebagai penipuan. Komunikasi pengguna tetap aman tanpa interupsi alarm palsu.

[4] Probabilitas Terkalibrasi Alami (Softmax)

Logistic Regression menghasilkan nilai probabilitas terkalibrasi murni 0 s.d. 100% via fungsi predict_proba(), sangat ideal untuk menggerakkan meteran keyakinan di web.

[5] Transparansi & Interpretabilitas Tinggi

Bobot koefisien (w) dapat dibedah secara transparan (*Explainable AI*) untuk memverifikasi kata apa yang memicu keputusan model (misal: [nomor], pinjaman, rekening).
